Глава — Политика конфиденциальности

Дата вступления в силу: 15 ноября 2026 г.

Настоящая политика описывает, какие данные обрабатывает приложение «Глава» (audiobook player, идентификатор app.glava) и как они защищаются. Ответственное лицо: Михаил Полгун, контакт: mikhailpolgun@gmail.com.

1. Общие принципы

Приложение работает с аудиокнигами, которые находятся на устройстве пользователя. Приложение не требует создания учётной записи, не содержит рекламы, аналитики, трекеров и push-уведомлений, не собирает и не передаёт персональные данные третьим лицам для маркетинговых целей.

2. Какие данные хранятся и где

Все данные приложения хранятся локально на устройстве в его приватном хранилище и включают:

  • список добавленных книг и их глав (названия и авторы берутся из метаданных выбранных пользователем аудиофайлов);
  • позицию прослушивания, закладки и статусы книг;
  • настройки приложения (тема, скорость воспроизведения, таймер сна и другие);
  • копии выбранных или найденных обложек книг.

Исходные аудиофайлы и изображения пользователя остаются в выбранных им папках: приложение читает их, не копируя и не изменяя.

3. Какие данные и куда передаются по сети

Приложение выходит в интернет только для поиска обложек книг в открытом каталоге Open Library (домены openlibrary.org и archive.org), если эта функция включена:

  • передаются: название книги и имя автора (из метаданных) по протоколу HTTPS;
  • получается: изображение обложки, найденное в каталоге.

Передача выполняется без идентификаторов устройства, без cookie и без привязки к пользователю. Автоматический поиск обложек отключается в настройках («Настройки → Обложки → Автоматический поиск обложек»); ручной поиск выполняется только по явному действию пользователя. При отключённой функции и без ручного поиска приложение не использует сеть.

4. Используемые разрешения Android

  • INTERNET — запрос обложек в Open Library;
  • FOREGROUND_SERVICE, FOREGROUND_SERVICE_MEDIA_PLAYBACK — фоновое воспроизведение аудио;
  • WAKE_LOCK — воспроизведение при выключенном экране.

Разрешения, опасные для приватности (геолокация, контакты, камера и т.п.), приложение не запрашивает.

5. Сроки хранения и порядок удаления данных

  • Данные не хранятся на каких-либо серверах: всё остаётся на устройстве.
  • Отдельная книга: удаление книги из библиотеки удаляет её записи, прогресс и обложку-копию из хранилища приложения; исходные файлы пользователя не затрагиваются.
  • Все данные приложения: полное удаление происходит при удалении приложения пользователем с устройства. Дополнительных действий не требуется, серверных копий не существует.

6. Возрастная категория

Приложение не содержит собственного медиаконтента; содержимое прослушиваемых книг выбирает сам пользователь из своих файлов.

7. Изменения политики

При существенных изменениях обработки данных политика обновляется на этой странице с новой датой вступления в силу. Продолжение использования приложения после публикации изменений означает согласие с обновлённой политикой.
